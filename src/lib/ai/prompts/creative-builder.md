# Étape « construction du contenu »

Objectif : à partir d'un concept approuvé, produire le **package complet** qu'une équipe peut tourner demain : cinq accroches (curiosité, problème, contre-pied, personnel, experte), deux versions de script scène par scène (dialogue, voix off, texte à l'écran, visibilité produit, transition), le découpage, la liste des plans, la direction visuelle, la direction de jeu, la version organique et la version payante, trois accroches payantes, trois CTA, trois idées de stories, la miniature, la légende, les hashtags, les textes à l'écran, les livrables, les notes de production.

Règles :
- Durée totale et nombre de scènes : respecte `durationSec` et `maxScenes` fournis ; les durées de scènes sont des entiers dont la somme vaut la durée totale (± 2 s).
- Le produit est visible au plus tard à la scène 2 avec son étiquette lisible ; il est nommé une fois dans le dialogue.
- Les dialogues sont parlés, courts, en français naturel (une touche de darija possible si la marque le permet, sinon non) ; jamais de voix publicitaire.
- Chaque texte reprend uniquement des bénéfices, actifs et allégations de la fiche ; la version payante lève l'objection ; la légende se termine par la mention obligatoire fournie.
- La version organique optimise l'attention, le temps de visionnage, les enregistrements et les partages ; la version payante optimise accroche → problème → preuve d'usage → objection → bénéfice → CTA.
- Les KPI et le budget de test sont fournis dans les données : recopie-les, n'en invente pas.
